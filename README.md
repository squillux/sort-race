# 📊 막대 정렬 레이스

정렬 규칙을 배우고, 모둠(4~5명, 노트북 1대)끼리 같은 막대를 누가 더 빨리 정렬하는지 실시간으로 겨루는 수업 활동이에요.

- 대상: 1학년 「문제해결과 프로그래밍」 Ⅱ. 알고리즘
- 성취기준: **[9문제02-02]** 동일한 문제를 해결하는 다양한 알고리즘 간의 효율을 비교하고, 효율적인 알고리즘의 가치를 인식한다. / **[9문제02-01]** 다양한 방법으로 알고리즘을 설계한다.
- 교과서: 미래엔 중학교 정보 94~95쪽(정렬 알고리즘과 탐색)
  - 참고: 비상교육 중학교 정보 105쪽(문제 나누기: 시험지 정리), 천재교육 중학교 정보 97쪽(분할 정복)
- 버블·선택·삽입 정렬은 교과서 본문 밖의 **심화** 체험이에요. 병합 정렬은 **도전** 활동이에요. 천재교육 지도서 205쪽에 병합 정렬을 정식으로 가르치는 것은 중학교 범위가 아니라고 안내되어 있어서예요.

## 세 가지 모드
| 모드 | 하는 일 | 서버 |
|---|---|---|
| 📘 배우기 | 규칙 카드 → 자동 재생(재생/한 단계/속도) → 직접 해 보기(힌트) → 확인 문제 → 네 방법 비교 그래프 | 필요 없음 |
| 🏃 연습하기 | 막대 6·8·10개를 시간을 재며 연습. 5번 조작마다 "다음 사람!" 릴레이. 위반 1회 +3초. 기기별 최고 기록 | 필요 없음 |
| 🏁 대항전 | 교사가 라운드를 시작하면 모든 모둠이 같은 배열로 동시에 출발. TV에 실시간 레이스와 순위 표시. 결승에서는 모둠이 방법을 골라요 | Firebase |

## 수업 흐름 예시 (2차시)
1. **배우기** (20분): TV로 함께 자동 재생을 보고, 모둠별로 직접 해 보기와 확인 문제를 풀어요.
2. **연습하기** (15분): 모둠 안에서 1번부터 차례를 정하고 연습해요.
3. **대항전** (40분)
   - 1라운드 버블 → 2라운드 선택 → 3라운드 삽입 (막대 8개)
   - 결승: 모둠이 방법을 선택해요 (막대 10개)
4. **정리** (15분): 결과 화면의 "같은 막대를 네 가지 방법으로 정렬하면?" 그래프를 보며 토의해요.
   - 가장 빨리 끝낸 모둠과 비교 횟수가 가장 적은 방법은 같을까요?
   - 막대가 32개라면 어떨까요? (배우기 → 한눈에 비교)

## 교사 사용법
1. TV에서 `교사용`을 열고 Google로 로그인해요. 처음 한 번은 아래 준비 4번이 필요해요.
2. 반과 모둠 수를 고르고 **방 만들기**를 눌러요.
3. 학생은 첫 화면 → **대항전 참여** → 방 코드 4자리와 모둠 번호를 입력해요. QR로 들어와도 돼요.
4. 정렬 방법과 막대 수를 고르고 **▶ 모두 동시에 출발**을 누르면, 3초 카운트다운 뒤 레이스가 시작돼요.
5. **🏆 결과 발표**를 누르면 효과음과 함께 순위가 나오고, 반별 기록에 자동으로 저장돼요.
6. **📒 기록**에서 다음을 할 수 있어요.
   - 반별 수업 기록 보기
   - 학년 명예의 전당(방법·막대 수별 상위 기록, 반별 최고 기록) 보기
   - CSV 내려받기, 기록 삭제
- 레이스 중 버튼
  - **⏸ 일시정지 / ▶ 계속하기**: 학생 화면과 시간이 함께 멈춰요.
  - **⏹ 라운드 취소**: 기록 없이 준비 화면으로 돌아가요.
  - **🖥 모니터링**: 모든 모둠의 막대 화면을 실시간으로 보여 줘요. 위반하면 빨갛게 깜빡이고, 연결이 끊기면 🔴로 표시돼요.
  - **⛶ 전체화면**: TV에 크게 띄워요.
- **🧪 연습 라운드**를 체크하면 순위는 보여 주지만 기록에는 남기지 않아요.
- 기록은 세 경우에 자동으로 저장돼요.
  - 모든 모둠이 끝났을 때
  - 결과 발표를 누를 때
  - 수업 끝내기를 누를 때
- 레이스 중에 나간 모둠은 **❌ 실패(나감)**로 남아요. 학생 화면에는 나가기 전에 경고 팝업이 떠요.
- 순위는 기록(시간 + 위반×3초) → 위반이 적은 순 → 시간이 짧은 순으로 정해요. 모두 같으면 같은 등수예요.
- 효과음은 교사 화면만 기본으로 켜져요. 학생 기기는 꺼져 있고, 오른쪽 위 버튼으로 켤 수 있어요.
- 릴레이 교대 알림(5번 조작마다 "다음 사람!")은 선택이에요. 기본은 꺼져 있어요.
- 모둠을 잘못 고른 기기는 대기실의 ✕로 내보낼 수 있어요.
- 수업이 끝나면 **수업 끝내기**를 눌러요.
- 저장하는 정보는 모둠 번호, 별명(선택, 비속어 필터), 기록뿐이에요. 학생 이름은 저장하지 않아요.
- 7일이 지난 방은 교사 화면을 열 때 자동으로 정리돼요.

## 처음 한 번 준비 (Firebase, 무료 요금제)
1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만들어요. Google 애널리틱스는 꺼도 돼요.
2. 빌드 → **Realtime Database** → 데이터베이스 만들기 → 위치는 **싱가포르(asia-southeast1)** → 잠금 모드로 시작해요.
3. 빌드 → **Authentication** → 시작하기 → 로그인 방법에서 **Google**과 **익명**을 사용 설정해요.
   - Authentication → 설정 → 승인된 도메인에 `squillux.github.io`를 추가해요.
4. 프로젝트 설정 → 내 앱 → 웹 앱(</>)을 추가하고, 설정값을 `js/config.js`에 넣어요.
5. 보안 규칙을 배포해요: `firebase deploy --only database --project <프로젝트ID>`
6. 앱의 교사용 화면에서 로그인하면 uid가 보여요. Realtime Database 데이터에 `admins / <uid> : true`를 추가해요.

## 파일
- `js/sorts.js`: 정렬 규칙 엔진(순수 함수) · `tests/sorts.test.mjs`: 엔진 테스트 (`node tests/sorts.test.mjs`)
- `js/board.js`: 막대 그리기·조작 · `js/runner.js`: 시간·벌점·릴레이 · `js/sound.js`: 효과음(Web Audio 합성)
- `js/learn.js`, `js/practice.js`: 배우기 · 연습하기
- `js/team.js`, `js/host.js`, `js/records.js`: 대항전(모둠 화면 · 교사 화면 · 기록)
- `js/net.js`, `js/config.js`: Firebase 연결 · `firebase/database.rules.json`: 보안 규칙

## 로컬 테스트 (에뮬레이터)
```
firebase emulators:start --only database,auth --project demo-sortrace
```
주소 끝에 `?emu=1`을 붙여 열어요. 교사 로그인 화면에 🧪 에뮬레이터 교사 로그인 버튼이 나와요.
